# Новый интерфейс и возврат к прежнему

Релиз: 27 октября 2026 года.

Внизу основной страницы есть кнопка «Вернуться к старому интерфейсу». Она переключает оформление на этом устройстве; обратная кнопка возвращает новый интерфейс. Переключатель также доступен в меню «Профиль и вид».

Поля формы переносятся через перезагрузку. При наличии выбранного файла или открытого договора переключение блокируется, чтобы не потерять незавершённую работу. Архив, серверная авторизация, API, шаблоны PDF и их зависимости общие для обоих интерфейсов.
